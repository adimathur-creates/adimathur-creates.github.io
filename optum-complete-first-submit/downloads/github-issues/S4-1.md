**Story.** As a coordinator, I want to submit the completed request electronically and get a tracking ID, so that I never fax.

**Feature.** F4 Submit and track through the Prior Authorization API

**Estimate.** 8 points · Sprint 2

### Acceptance criteria

```gherkin
Given a complete request
When I press Submit
Then it is sent through the Prior Authorization API and a tracking ID comes back within 5 seconds
And a failed send is retried and shown clearly, never silently dropped
```

### Definition of done

- [ ] All acceptance criteria pass in a test environment
- [ ] Automated tests added and green
- [ ] Peer review done; no new security findings
- [ ] Audit logging in place for any read of patient data
- [ ] Accessibility checked (WCAG 2.1 AA) for any screen
- [ ] Product owner accepted it in the sprint review
- [ ] Help text and release note updated
