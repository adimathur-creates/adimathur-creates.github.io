**Story.** As a coordinator, I want a short list of only the unanswered required questions, so that I can finish the request in one sitting.

**Feature.** F3 Ask only what is missing, before submit

**Estimate.** 5 points · Sprint 2

### Acceptance criteria

```gherkin
Given required questions are unanswered
When I press Submit
Then submit is held and the missing items are listed with a one-line reason each
And answering them enables Submit
```

```gherkin
Given all required questions are answered
When I press Submit
Then the request is sent with no extra screen
```

### Definition of done

- [ ] All acceptance criteria pass in a test environment
- [ ] Automated tests added and green
- [ ] Peer review done; no new security findings
- [ ] Audit logging in place for any read of patient data
- [ ] Accessibility checked (WCAG 2.1 AA) for any screen
- [ ] Product owner accepted it in the sprint review
- [ ] Help text and release note updated
