**Story.** As the product team, we want to test with clinical policy whether structured answers can replace the 30-day note for low-risk requests, so that we remove the biggest remaining cause of pends.

**Feature.** F7 Challenge the 30-day note rule

**Estimate.** 2 points · Sprint 2 (spike)

### Acceptance criteria

```gherkin
Given a sample of 100 past pended requests
When clinical policy reviews them with and without the note
Then we record how often the note changed the decision, and decide keep, relax or drop
```

### Definition of done

- [ ] All acceptance criteria pass in a test environment
- [ ] Automated tests added and green
- [ ] Peer review done; no new security findings
- [ ] Audit logging in place for any read of patient data
- [ ] Accessibility checked (WCAG 2.1 AA) for any screen
- [ ] Product owner accepted it in the sprint review
- [ ] Help text and release note updated
