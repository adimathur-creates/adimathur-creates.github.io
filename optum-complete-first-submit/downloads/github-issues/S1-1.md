**Story.** As a prior-auth coordinator, I want to see whether a lumbar MRI order needs prior auth, and what documentation is required, while the order is still open, so that I don't check a portal later.

**Feature.** F1 Coverage check at order

**Estimate.** 5 points · Sprint 1

### Acceptance criteria

```gherkin
Given a clinician signs an order for CPT 72148 for a member of a plan in scope
When the order is signed
Then the order shows "Prior auth required: documentation needed" within 2 seconds at the 95th percentile
And the card links to the questionnaire
```

```gherkin
Given the coverage service is down
When the order is signed
Then the order shows "Could not check: use the portal" and the order is never blocked
```
