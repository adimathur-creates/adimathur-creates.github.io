**Story.** As a clinician, I want to confirm red flags with one tap inside the order, so that I am not pulled back days later.

**Feature.** F3 Ask only what is missing, before submit

**Estimate.** 3 points · Sprint 2

### Acceptance criteria

```gherkin
Given the red-flag question is unanswered
When the clinician signs the order
Then a one-tap prompt offers "None" or the listed red flags
And the answer records who confirmed it and when
```

### Definition of done

- [ ] All acceptance criteria pass in a test environment
- [ ] Automated tests added and green
- [ ] Peer review done; no new security findings
- [ ] Audit logging in place for any read of patient data
- [ ] Accessibility checked (WCAG 2.1 AA) for any screen
- [ ] Product owner accepted it in the sprint review
- [ ] Help text and release note updated
