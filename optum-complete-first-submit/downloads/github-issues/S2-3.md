**Story.** As an ordering clinician, I want "no red flags" to be something I confirm, not something the system assumes from a blank chart, so that the request is accurate.

**Feature.** F2 Pre-filled documentation questionnaire

**Estimate.** 3 points · Sprint 1

### Acceptance criteria

```gherkin
Given no red-flag condition is coded in the chart
When the questionnaire opens
Then the red-flag question is left for the clinician, not filled as "none"
```

```gherkin
Given a red-flag condition is coded (for example history of cancer)
When the questionnaire opens
Then the red-flag answer is filled with that condition and marked "from chart"
```

### Definition of done

- [ ] All acceptance criteria pass in a test environment
- [ ] Automated tests added and green
- [ ] Peer review done; no new security findings
- [ ] Audit logging in place for any read of patient data
- [ ] Accessibility checked (WCAG 2.1 AA) for any screen
- [ ] Product owner accepted it in the sprint review
- [ ] Help text and release note updated
