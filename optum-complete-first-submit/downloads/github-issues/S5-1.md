**Story.** As a coordinator, I want a pend notice that lists exactly what is missing and how to send it, so that I fix it in one try.

**Feature.** F5 Specific reasons and what to send

**Estimate.** 3 points · Sprint 2

### Acceptance criteria

```gherkin
Given a request is pended for missing information
When the notice is sent
Then it names each missing item, for example "office note from the last 30 days", and links to upload it
```

### Definition of done

- [ ] All acceptance criteria pass in a test environment
- [ ] Automated tests added and green
- [ ] Peer review done; no new security findings
- [ ] Audit logging in place for any read of patient data
- [ ] Accessibility checked (WCAG 2.1 AA) for any screen
- [ ] Product owner accepted it in the sprint review
- [ ] Help text and release note updated
