**Story.** As a member, I want the plan to read only the parts of my record it needs, so that my privacy is respected.

**Feature.** F2 Pre-filled documentation questionnaire

**Estimate.** 3 points · Sprint 1

### Acceptance criteria

```gherkin
Given the questionnaire rules run
When they query the chart
Then they request only the resource types the questions need (HIPAA minimum necessary)
And every query is written to an audit log with user, time and purpose
```

### Definition of done

- [ ] All acceptance criteria pass in a test environment
- [ ] Automated tests added and green
- [ ] Peer review done; no new security findings
- [ ] Audit logging in place for any read of patient data
- [ ] Accessibility checked (WCAG 2.1 AA) for any screen
- [ ] Product owner accepted it in the sprint review
- [ ] Help text and release note updated
