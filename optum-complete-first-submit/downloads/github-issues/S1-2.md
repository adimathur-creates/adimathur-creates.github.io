**Story.** As a coordinator, I want a clear "No prior auth needed" result with a reference number, so that I can schedule straight away.

**Feature.** F1 Coverage check at order

**Estimate.** 3 points · Sprint 1

### Acceptance criteria

```gherkin
Given the service does not need prior auth for this member
When the order is signed
Then the card says "No prior auth needed" with a reference number and date
And the reference is saved on the order
```

- [ ] All acceptance criteria pass in a test environment
