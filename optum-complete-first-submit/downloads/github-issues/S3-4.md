**Story.** As a coordinator, I want to save a half-finished request and come back to it, so that I can wait for a missing note.

**Feature.** F3 Ask only what is missing, before submit

**Estimate.** 3 points · After go-live

### Acceptance criteria

```gherkin
Given a request has unanswered items
When I choose Save draft
Then the draft and its answers are kept for 14 days and listed in my queue
```
