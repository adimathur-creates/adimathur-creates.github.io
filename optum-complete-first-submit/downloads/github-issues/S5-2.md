**Story.** As a clinician, I want a denial to state the specific reason and the appeal steps, so that I know what to do next.

**Feature.** F5 Specific reasons and what to send

**Estimate.** 3 points · Sprint 3

### Acceptance criteria

```gherkin
Given a clinician reviewer denies a request
When the decision is sent
Then it includes the specific reason, the criteria used, and how to appeal or request a peer-to-peer review
```

### Definition of done

- [ ] All acceptance criteria pass in a test environment
- [ ] Automated tests added and green
- [ ] Peer review done; no new security findings
- [ ] Audit logging in place for any read of patient data
- [ ] Accessibility checked (WCAG 2.1 AA) for any screen
- [ ] Product owner accepted it in the sprint review
- [ ] Help text and release note updated
