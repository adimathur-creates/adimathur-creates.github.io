**Story.** As a health plan, I want complete requests that clearly meet the rules approved in real time, and everything else sent to a clinician, so that we are fast and never auto-deny.

**Feature.** F4 Submit and track through the Prior Authorization API

**Estimate.** 5 points · Sprint 3

### Acceptance criteria

```gherkin
Given a complete request meets the rules
When it is received
Then it is approved within seconds with the rules that were met listed
```

```gherkin
Given a complete request does not meet the rules
When it is received
Then it goes to the clinician review queue and is never denied automatically
```

### Definition of done

- [ ] All acceptance criteria pass in a test environment
- [ ] Automated tests added and green
- [ ] Peer review done; no new security findings
- [ ] Audit logging in place for any read of patient data
- [ ] Accessibility checked (WCAG 2.1 AA) for any screen
- [ ] Product owner accepted it in the sprint review
- [ ] Help text and release note updated
