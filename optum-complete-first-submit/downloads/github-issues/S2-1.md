**Story.** As a coordinator, I want the plan's questions pre-filled from the chart, so that I don't re-type what is already there.

**Feature.** F2 Pre-filled documentation questionnaire

**Estimate.** 8 points · Sprint 1

### Acceptance criteria

```gherkin
Given the chart has a back-pain diagnosis with an onset date, coded PT visits or an NSAID prescription
When the questionnaire opens
Then diagnosis, weeks of pain and weeks of conservative care are filled in
And each filled answer is marked "from chart"
```

```gherkin
Given a value is not in the chart as data
When the questionnaire opens
Then that question is left blank, never guessed
```

### Definition of done

- [ ] All acceptance criteria pass in a test environment
- [ ] Automated tests added and green
- [ ] Peer review done; no new security findings
- [ ] Audit logging in place for any read of patient data
- [ ] Accessibility checked (WCAG 2.1 AA) for any screen
- [ ] Product owner accepted it in the sprint review
- [ ] Help text and release note updated
