**Story.** As a member, coordinator or clinician, I want to see the request status and the date a decision is due, so that nobody has to call to ask.

**Feature.** F4 Submit and track through the Prior Authorization API

**Estimate.** 5 points · Sprint 2

### Acceptance criteria

```gherkin
Given a request is submitted as urgent
When anyone with access views it
Then it shows status and a decision due within 72 hours
```

```gherkin
Given a request is submitted as standard
When anyone with access views it
Then it shows a decision due within 7 calendar days
And status is also available to the member through the patient access API
```

### Definition of done

- [ ] All acceptance criteria pass in a test environment
- [ ] Automated tests added and green
- [ ] Peer review done; no new security findings
- [ ] Audit logging in place for any read of patient data
- [ ] Accessibility checked (WCAG 2.1 AA) for any screen
- [ ] Product owner accepted it in the sprint review
- [ ] Help text and release note updated
