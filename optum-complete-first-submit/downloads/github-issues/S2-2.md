**Story.** As a nurse reviewer, I want each pre-filled answer to show where it came from, so that I can trust it without opening every document.

**Feature.** F2 Pre-filled documentation questionnaire

**Estimate.** 3 points · Sprint 3

### Acceptance criteria

```gherkin
Given an answer was pre-filled
When the reviewer opens the request
Then the answer shows its source, for example "PT visit 10 Sep 2026" or "Ibuprofen 3 Sep to 29 Oct"
```

### Definition of done

- [ ] All acceptance criteria pass in a test environment
- [ ] Automated tests added and green
- [ ] Peer review done; no new security findings
- [ ] Audit logging in place for any read of patient data
- [ ] Accessibility checked (WCAG 2.1 AA) for any screen
- [ ] Product owner accepted it in the sprint review
- [ ] Help text and release note updated
